Gestor de Publicações para YouTube

O Gestor de Publicações é uma ferramenta de uso pessoal de Johann Benner para organizar e agendar vídeos de ensino de Libras nos canais que ele administra. Somente o responsável autoriza a ferramenta a acessar os próprios canais. Esta página explica a integração. Ela não oferece cadastro, login ou acesso ao Gestor.

A ferramenta lê os vídeos, as capas e os arquivos de texto na pasta autorizada do Google Drive. Usa os Serviços da API do YouTube para confirmar o canal autorizado, prevenir publicações duplicadas, agendar Shorts, aplicar miniaturas e verificar os resultados. Para Instagram, TikTok e Facebook, usa o Buffer. A execução recorrente está suspensa enquanto a integração em nuvem é preparada.

Ao usar o Gestor de Publicações, o responsável concorda com os Termos de Serviço do YouTube. A Política de Privacidade explica quais dados são utilizados e como solicitar sua exclusão.
